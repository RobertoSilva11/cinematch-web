1. Objetivo do Sistema

SCTEC | SENAI

Aplicar a lógica de recomendações inteligentes e consumo de APIs externas para solucionar o problema da indecisão na escolha de séries.

  • Cruzar preferências do usuário (gêneros e idade) com o catálogo.
  • Gerar cálculos dinâmicos de afinidade (Match%).
  • Consumir o catálogo real e atualizado via TVMaze API.

Como rodar o sistema?

O projeto roda nativamente no lado do cliente (Front-end), sem necessidade de banco de dados.

  • Basta clonar o repositório do GitHub.
  • Abrir o arquivo index.html no navegador.
  • Ou utilizar a extensão Live-Server do VS Code / Node.js.
